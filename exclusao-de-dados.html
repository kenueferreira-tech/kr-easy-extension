Solicitar exclusão de dados

O KR Easy Extension não cria conta de usuário. Ainda assim, alguns dados relacionados à licença e à compra podem ser tratados para liberar o acesso, prevenir fraude e cumprir obrigações legais. Rascunhos e preferências ficam armazenados no aparelho.

Como fazer o pedido

Envie uma solicitação para o suporte. Informe o e-mail usado na compra e, se tiver, a referência do pedido. Não envie sua senha, dados do cartão nem a chave completa da licença.

Enviar pedido de exclusão

O que será analisado

O suporte verificará os dados associados ao pedido e à licença e removerá os dados que puderem ser excluídos. Alguns registros mínimos poderão ser mantidos quando necessário para cumprir obrigações legais, resolver disputas ou prevenir fraude. O suporte informará o resultado do pedido.

Dados guardados no aparelho

Para apagar rascunhos, scripts e preferências locais, use as configurações do Android para limpar os dados do KR Easy Extension ou desinstale o aplicativo. Isso não envia uma solicitação de exclusão dos registros mantidos pelos provedores; para esses, use o botão de pedido acima.

Consulte também a Política de Privacidade. Dúvidas: suporte.kreasy@gmail.com.
